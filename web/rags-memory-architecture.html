RAGS — Memory Vector Architecture

Retrieval-Augmented Generation with Persistent Memory — Vector Graph Overview

Vector Memory Store

  • • HNSW / IVF indexes for fast similarity search
  • • Fact, semantic, and working memory partitions
  • • Persistent storage of embeddings + metadata
  • • Store / Retrieve / Consolidate operations

Pipeline Flow

  • • Query → Embedding → Retrieval → Augmentation
  • • Context builder merges retrieved chunks with prompt
  • • LLM generates response from augmented context
  • • Feedback loop writes results back to memory

Key Design Choices

  • • Retrieval quality depends on embedding model
  • • Memory consolidation prevents unbounded growth
  • • Metadata filtering enables multi-hop retrieval
  • • Feedback-driven memory update closes the loop
